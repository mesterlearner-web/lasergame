# فایل‌های صوتی

از فاز۱۰ این پوشه **۱۵ فایل OGG/Vorbis واقعی** دارد (۹ نوع افکت با چند نسخه + ۲ موسیقی‌ی حلقه‌ای،
جمعاً ≈۲۴۰KB). صداها با *سنتز رویه‌ای* ساخته شده‌اند (`python tools/generate_audio.py`؛ فقط کتابخانه‌ی
استاندارد پایتون + ffmpeg برای کدگذاری OGG) -- یعنی صدای «طراحی‌شده‌ی حرفه‌ای» نیستند، و هیچ انسانی
هنوز با گوش نسنجیده‌شان؛ تنظیم بلندی/حس نهایی فقط روی گوشی ممکن است.

## جایگزین‌کردن با صدای حرفه‌ای
هر فایل را با **همان نام** کپی کنید (نام‌های کامل در `SFX_VARIANTS`/`MUSIC_TRACKS` در
`core/audio_manager.py`؛ `tests/test_phase10.py` تضمین می‌کند هر نام فایل دارد و فایل اضافه‌ای نیست).
فایل OGG با نرخ نمونه‌ی ۲۲۰۵۰ تا ۴۴۱۰۰ و حجم زیر ۲۰۰KB؛ موسیقی بهتر است حلقه‌ی بی‌تق باشد.

## فهرست
- افکت‌ها: `mirror_hit_1..3`, `target_destroy_1..2`, `obstacle_hit_1`, `shot_fire_1..2`, `level_win`,
  `level_lose`, `low_time_warning`, `button_tap`, `purchase`
- موسیقی: `menu_theme`, `gameplay_theme`

اگر فایلی نباشد `AudioManager` سکوت می‌کند (کرش نمی‌کند).
